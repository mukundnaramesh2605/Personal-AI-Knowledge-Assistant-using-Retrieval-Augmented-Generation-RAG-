# Hauler X2 - Setup Guide

## Step 1: Unboxing
Remove the robot from the crate and check for the included charging dock and remote.

## Step 2: First Charge
Charge the robot fully before first use. A full charge takes **90 minutes**.

## Step 3: Mapping the Warehouse
Drive the robot manually once around the warehouse so it can build its first map.
This mapping run should take about **15 minutes**.

## Step 4: Go Autonomous
Press the green **AUTO** button to start autonomous operation.

> Tip: Keep the firmware updated. The current firmware version is **v3.4.1**.
